# Thematic coding protocol

The qualitative strand used analyst-coded thematic description of the four open-ended evaluation prompts: learning value, what respondents liked most, suggested improvements, and additional comments. The unit of analysis was one respondent answer to one prompt. A response could receive more than one code when it contained distinct ideas.

Responses such as `N/A`, `NA`, `none`, `nothing specific`, punctuation-only entries, or equivalent non-answers were assigned `NO_SUBSTANTIVE_RESPONSE`. Brief positive comments such as `Kudos` or `All good` were retained as `OTHER_RELEVANT_FEEDBACK` when they communicated an evaluative reaction but did not fit a more specific code. The codebook was applied to the de-identified response fields; the coding table contains no institution, timestamp, attendance link, or full response text.

The coding was completed by the analyst for this manuscript. No second coder or inter-rater agreement statistic was available, so the themes should be read as a transparent descriptive coding of reported comments rather than as a validated qualitative measurement. Theme frequencies indicate how often a code was assigned, not how many participants objectively learned a concept, and they do not support causal or population-level claims.
