# Thematic coding assets

`codebook.json` defines the analyst-coded themes. `coding_decisions.csv` records de-identified respondent-field/code assignments and contains no institutions, timestamps, attendance links, or full response text. Multiple codes may be assigned to one response field when it contains distinct ideas.

The analysis reports these as themes in participant comments. Frequency is descriptive and does not establish learning, causation, or generalizability.
